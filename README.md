# Travel Expense Splitter

A responsive web app for tracking travel expenses, splitting costs with friends, and calculating settlements across different currencies.

## Demo

https://travel-expense-splitter-git-main-houkerrys-projects.vercel.app/

## Features

- Add, edit, and delete members
- Add, edit, delete, sort, and export expenses
- Split each expense with selected participants
- Support personal expense tracking when no members are added
- Expense categories with visual badges
- Notes and dates for each expense
- Manual exchange rates and base currency selection
- Category summary and settlement summary
- Copy settlement results and expense list
- Export expenses as CSV
- Save data locally with localStorage
- Custom theme color

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Vercel

## Project Purpose

This project was built to solve a common problem during group trips: tracking expenses and calculating who should pay whom.  
The goal is to create a simple, intuitive, and browser-based tool that does not require installation or login.
